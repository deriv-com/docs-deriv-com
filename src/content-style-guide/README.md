# Deriv content style guide 2026

Created by the Content Team. This repo is a quick reference for Deriv content writers, split into one file per section so it's easy to link to, search, and update in isolation.

## Important things to remember

- Write clearly and concisely. Always aim for accuracy.
- Make it as easy as possible to understand. Use appropriate language for the target audience.
- Deriv clients are global; many of them aren't native English speakers. Content may be translated into other languages, so use simple language as much as possible.
