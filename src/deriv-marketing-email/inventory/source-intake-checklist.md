# Source intake checklist

Use this checklist before adding any source to the repository.

## Authority and currency

- [ ] The source has an identifiable owner.
- [ ] Its approval status is known.
- [ ] Its version or last-updated date is recorded.
- [ ] Its effective and expiry dates are recorded where relevant.
- [ ] Superseded versions are identified.
- [ ] Conflicts with other sources are documented.

## Data handling

- [ ] Customer and account data have been removed.
- [ ] Credentials and secret URLs have been removed.
- [ ] Confidentiality is classified.
- [ ] Use on each intended AI platform is approved.
- [ ] The repository location is appropriate for the source's sensitivity.

## Content preparation

- [ ] Screenshot-only guidance has been converted into text where practical.
- [ ] Tables have clear headings.
- [ ] Exact mandatory wording is separated from examples.
- [ ] Temporary facts are labelled as volatile or task-specific.
- [ ] Market and audience applicability are explicit.
- [ ] Reusable guidance is separated from campaign-specific detail.

## Ingestion decision

- [ ] Include as canonical knowledge.
- [ ] Include only as a reference.
- [ ] Include as an annotated example.
- [ ] Supply at runtime instead.
- [ ] Exclude.
