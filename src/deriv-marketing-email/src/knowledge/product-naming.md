# Product and account naming

Use the current spelling and case exactly.

## Platforms and accounts

| Use | Avoid |
|---|---|
| Deriv MT5 | dMT5, Mt5, mt5 |
| MT5 Standard demo | MT5 demo Standard, MT5 Demo Standard, MT5 Standard Demo |
| Zero Spread | unapproved variations |
| Swap-Free | swap free, Swap free |
| Deriv cTrader | Dctrader, DCTRADER |
| Deriv GO | Deriv go, Deriv Go |
| Deriv Bot | dBot, DerivBot |
| Deriv Trader | DTrader, dTrader, DT |
| SmartTrader | smart trader, Smart Trader, ST |
| Wallet | wallet when referring to the Deriv product |
| US dollar Wallet | US Dollar Wallet, US dollar wallet |
| USD Wallet | USd Wallet, usd Wallet |

## Product applicability

Do not infer that a product, account type, market, or trade type is available in a jurisdiction. The glossaries explicitly distinguish products that are not available in the EU or that use different UAE definitions.
