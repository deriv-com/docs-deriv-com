# Example policy

Examples teach structure, audience framing, sequencing, correction patterns, and CTA treatment. They do not authorise current facts.

- `approved/`: useful historical patterns with volatile details clearly isolated.
- `review-required/`: source conflicts or high-risk content that must not be used without confirmation.
- `anti-examples/`: content explicitly rejected or unsuitable as a positive pattern.

The build includes annotations and selected copy, not historical footers as disclosure authority.
