# Source extracts

This directory contains plain-text extracts of the uploaded PDFs so changes can be reviewed and retrieval can work without relying on screenshots.

The PDFs themselves are not copied into the repository by default. Keep them in the approved internal document system and use `sources/manifest.csv` to verify source identity.

Raw extracts are not automatically canonical. Curated rules in `src/` and structured data in `data/` control platform distributions. The glossary extracts are included in distributions as reference files because the market and platform columns contain detail that should not be flattened into a short summary.
