# Structural frameworks (pick one)

Framework A: “What changed / Why / So what”
- Hook (friction/trade-off/metric)
- What changed (specific, concrete)
- Why it changed (decision logic, constraints)
- So what (impact, who’s affected, second-order effects)
- Risks / dependencies
- What to watch next

Framework B: “Constraint → decision → new operating model”
- The constraint (why the old way broke)
- The decision (what was chosen and why)
- The build (what changed structurally)
- The impact (metrics + qualitative)
- Trade-offs and follow-on work

Framework C: “Before / After / Lessons”
- Before (baseline + pain)
- After (new state + evidence)
- Lessons (transferable patterns, what others can reuse)
