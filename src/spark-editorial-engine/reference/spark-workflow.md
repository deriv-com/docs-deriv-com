# Spark workflow outputs

Default flow (don’t call it Stage 1/2/3 unless asked):

1) Angle clarity (no drafting)
- Ask one question at a time, in this order:
  a) What article are you trying to write?
  b) What happened?
  c) Who is affected?
  d) Why does it matter?
- Then deliver:
  - 3–5 line summary
  - Primary pillar + format + strategic intent
  - Core impact question (1 sentence)
  - Underlying tension (1 sentence)
  - Reporting need: None/Light/Moderate/Heavy + why
  - Quick check: analytical vs descriptive; measurable impact; structural implication
  - If weak: 2–3 stronger one-sentence angles
- End with: “Want me to sketch an outline?”

2) Structure (outline + reporting plan)
A) Outline
- Use a Spark-native skeleton (see structural frameworks file).
- Label where to add: tension, metrics, decision logic, structural insight, “why this matters”.
- Provide 3 hook options in Spark voice (choose from: friction / counterintuitive / metric / trade-off).
B) Reporting plan
- Recommend 0–4 interviews.
- Roles + teams only (no names unless given).
- For each interview: purpose + 3–5 questions focused on reasoning, constraints, trade-offs, impact.
- Evidence checklist (only relevant): KPIs + definitions, release notes/changelog, before/after, dashboards/visuals.
- End with: “Want me to stress-test this outline for depth before we draft?”

3) Depth (critique + reporting validation + draft readiness)
A) Depth check
- Flag gaps: tension/constraints, measurable impact, decision logic, trade-offs/risks/dependencies, leadership relevance, PR tone.
- Provide specific fixes (where + how).
- If opening reads like an announcement, rewrite first 2–3 sentences using an approved hook type.
B) Reporting plan check
- Sufficient/overkill/misaligned + final interview count + order + what each must unlock.
C) Draft readiness
- Ready to draft now / Draftable with placeholders / Not ready (max 3 missing inputs)
- If placeholders: list them.
- End with: “Do you want a revised outline first, or a draft with placeholders?”
