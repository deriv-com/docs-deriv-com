# deriv-ux-writing
 
Source of truth for Deriv's UX writing standards -- voice, tone,
terminology, and reusable copy.
 
## Contents
- `SKILL.md` -- the UX writing guideline: tone, copy patterns by
  element, character limits, terminology hard rules, and the audit
  checklist.
- `References/product-glossary.md` -- Deriv-approved terminology, in
  three tiers:
  1. Curated entries (Display name / Tooltip / UX copy notes) for
     terms in active use -- trade types, platform names, Deriv
     Tokens, Deriv P2P.
  2. An EU availability quick reference for curated terms also in
     the master glossary.
  3. Extended terminology from the March 2026 master glossary,
     covering terms not yet UX-curated.
- `References/crypto-glossary.md` -- industry reference for
  crypto/blockchain terminology (Binance Academy, paraphrased).
  Background reading, not a source of Deriv-approved UI copy.
## Merge history
Merged in August 2026 with a teammate's (Himawan) copy of this
skill, which had pulled in a newer master glossary plus Deriv P2P
and crypto terminology this skill didn't have yet. See SKILL.md's
"Deriv P2P" sections and the glossary's "Extended terminology"
section for what came in from that merge.
 
## Ownership
Maintained by the UX team. Changes go through review to keep the
standards consistent and this README in sync with the folder.
